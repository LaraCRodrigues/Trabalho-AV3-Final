Linguagem: C

Funcionalidades
- Cadastro de músicas
- Busca por ID
- Alteração de músicas
- Exclusão de músicas
- Listagem de músicas
- Relatório com quantidade de músicas cadastradas

Como executar no OnlineGDB

1. Acesse o site https://www.onlinegdb.com/online_c_compiler.
2. Apague o código de exemplo.
3. Copie todo o conteúdo do arquivo `sistema-de-lista.c`.
4. Cole o código no editor.
5. Clique em **Run** para compilar e executar o programa.

**Observações

- O programa foi desenvolvido no onlineGDB para evitar conflitos entre windowns e linux.
- O programa foi desenvolvido utilizando vetor de `struct`, conforme solicitado no Trabalho A (Listas Simples).
- O sistema realiza validações para impedir IDs inválidos, campos vazios e duração em formato incorreto.
- A duração deve ser informada no formato **MM:SS** (exemplo: `03:45`).
